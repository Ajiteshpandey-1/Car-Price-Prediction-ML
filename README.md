# 🚗 Car Price Prediction using Machine Learning
## 📌 Project Overview
This project focuses on predicting car prices using Machine Learning.
The model uses different numerical and categorical features of cars and applies **Linear Regression** to predict the price.
## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab

## 🔧 Machine Learning Workflow
1. Data Loading
2. Data Cleaning
3. Handling Missing Values
4. Feature Selection
5. Numerical Feature Preprocessing
6. Categorical Feature Preprocessing
7. One-Hot Encoding
8. ColumnTransformer
9. Train-Test Split
10. Machine Learning Pipeline
11. Linear Regression
12. Model Evaluation
13. Sample Price Prediction

## 📊 Model Performance
- **R² Score:** 0.88
- **Mean Absolute Error:** $1,560.72

## 🚘 Sample Prediction
For a sample Toyota sedan with the given specifications, the model predicted a price of:
**$11,340.93**

## 📂 Project Files
- `CAR_predict_by_ml.ipynb` — Complete Machine Learning notebook containing
-  data preprocessing, model training, evaluation, and prediction.
